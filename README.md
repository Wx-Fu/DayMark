# DayMark · 时序

一个 macOS 任务记录与提醒应用，用于同时查看多个任务的时间安排。数据保存在本机，无需账号或联网。

- 记录事项、开始和结束时间、优先级、备注与重复周期。
- 通过甘特时间轴查看并行任务和当前时间，支持横向滚动。
- 使用 macOS 系统通知提醒，可在应用内发送测试通知。
- 选择日期与时间时，可用 ⌘1–⌘5 设置 30 分钟、1 小时、2 小时、4 小时或 1 天的时长；⌘0 将开始时间设为当前时间。

## 构建与运行

需要 macOS 13 或更新版本、Swift 编译器和 Xcode Command Line Tools。在仓库目录执行：

```sh
./scripts/build.sh
open build/Daymark.app
```

构建脚本为当前 Mac 的处理器架构编译应用，并使用本地临时签名。首次使用提醒时，在应用右上角开启通知权限，并可发送测试通知。提醒时间按事项结束时间计算。

事项数据位于 `~/Library/Application Support/Daymark/`，可通过应用侧栏的导出按钮备份。
